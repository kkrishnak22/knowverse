Learn it by doing it. Start with a mission: drive a rover on Mars that does only what you tell it. Then try the same idea with a robot and a kitchen.

```kv-rover
```

Now try the same idea on Earth. Give the robot its steps.

```kv-robot
title: Take the robot to the star
.....
.>.*.
.....
---
title: The star is round the corner
....
.>..
...*
---
title: Go around the wall
.....
.>#*.
.....
```

The robot did only what you told it, in the order you told it. A computer works the same way. Your list of steps is called a [[What is a program?|program]].

The order of the steps matters too. These steps make tea, but they are mixed up. Put them in order.

```kv-tea
```

The kitchen robot never fixed your steps. It boiled an empty kettle if you told it to. A computer does the same: it follows your steps, right or wrong.

```kv-quiz
? The robot hit a wall. Why?
- It got confused
+ It did exactly the step it was given
- It wanted to go that way
> The robot never decides anything. It does the step you wrote, even when the step is wrong.

? In what order did the robot do your steps?
+ From the first step to the last, one at a time
- All at the same time
- Any order it liked
> One step, then the next. Every program runs this way.

? You poured the kettle before you boiled it. What did the robot do?
- It boiled the water first, because that makes sense
+ It poured cold water, exactly as told
- It stopped and asked you
> A computer does not know what makes sense. It only knows the order you gave.

? What is programming?
- Guessing what a computer wants
+ Telling a computer exactly what to do, one step at a time
- Building a computer
> You write the exact steps. The computer follows them.
```
